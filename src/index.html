PROYECTOS

Free News

Free News es un programa de ordenador creado con el proposito de mantenerse actualizado de manera gratuita, saltándose el muro de pago de diversos portales de noticias (El País, ABC, Diario Sur, etc). Este software lo desarrolle como un proyecto rápido durante las vacaciones de Navidad.

Consta de dos partes: La parte lógica, que esta hecha con Python y diversas librerías (BeautifulSoup y urllib.request son las más importantes) y la parte de interfaz, construida con JavaFX. Es un proyecto al que le tengo mucho cariño, porque aunque aún este en un estado mejorable, me sirvió de gran manera para mejorar mis habilidades en Python y el desarrollo de interfaces en Software de ordenador.

Probador Virtual

Probador Virtual es mi aplicación que aún se encuentra en proceso de desarrollo.

A quién no le ha pasado alguna vez estar comprando y probando ropa y llegar a probarse un conjunto increíble, pero hay un pequeño problema, no tienes el dinero suficiente. Así que te haces una foto y se guarda en tu galería el outfit tan bello que te probaste. Pero el tiempo pasa y la galería se va llenando de fotos y vídeos, y el conjunto que te ibas a comprar se queda en el olvido de tu mente y en el batiburrillo de imagenes. ¡Probador virtual soluciona justo ese problema!

Ahora podrás guardar tus conjuntos en una sola aplicación, junto a la información de cada artículo y producto y podrás consultarlo siempre que quieras, para que la próxima vez que vayas de compra no se te olvide la ropa que te quedaba bien.

Está aplicación será mi TFG y usa tecnologías como SQLite, Android Studio y más.

Lector de alimentos

Aplicación aún en desarrollo.

Lector de alimentos lee los códigos de barras de productos alimenticios y muestra el valor nutricional. Consta de una comunicación con la API OpenFoodFacts y una base de datos propia para agregar alimentos que no se encuentran en la API.

Está aplicación me enseña como usar una API para una aplicación de Android y la utilización de base de datos en la nube.
